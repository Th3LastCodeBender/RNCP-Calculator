Persone: dimensione del team indicata sull'intra (ottobre 2026, aggiornabile con npm run info). Può cambiare tra campus e versioni del subject. Subject: apre il PDF ufficiale sul CDN di 42, senza login (ottobre 2026; npm run info segnala i link cambiati). Pagina del progetto: apre la pagina sull'intra, dove trovi sempre il PDF più recente (serve il login 42).
