RNCP Calculator

Importa i tuoi progetti fatti e in corso, i voti e il livello dall'intra.

XP: valore a voto 100, dall'intra (ottobre 2026, aggiornabile con npm run info). Gli XP reali scalano con il voto finale. Per le piscine il totale vale solo se validi tutti i moduli; per contare come progetto basta l'ultimo.

Giorni: tempo stimato dall'intra diviso per le tue Ore al giorno (da 1 a 24, default 8), con sabato e domenica liberi: ogni 5 giorni lavorativi si aggiungono 2 giorni di weekend. Le ore esatte compaiono passando sopra il chip. Si aggiornano con npm run hours. Linguaggio: indicativo, "Libero" vuol dire a scelta: fa fede il subject.

Persone: dimensione del team indicata sull'intra (ottobre 2026, aggiornabile con npm run info). Può cambiare tra campus e versioni del subject.

Subject: apre il PDF ufficiale sul CDN di 42, senza login (ottobre 2026; npm run info segnala i link cambiati). Pagina del progetto: apre la pagina sull'intra, dove trovi sempre il PDF più recente (serve il login 42).

Requisiti comuni (livello 17, 10 eventi, 2 esperienze professionali): si scrivono a mano nei riquadri in alto; il livello arriva anche da npm run me. Il livello col piano somma al livello attuale gli XP dei progetti scelti non ancora fatti, a voto 100. Un progetto presente in più blocchi è contato in ognuno: conferma sulla pagina RNCP dell'intra.
